> **CF 轨**: `embs/amazon-baby-mmssl_seed2026_..._nl4_mm_mr0.001_mt0.1_fc0.8_pr32.pkl`（官方 R@20=0.0913）

## 0. 结论速览

| 实验 | 结论 | 判定 |
|---|---|---|
| **M3 e_u 画像** | 画像含真实偏好信号（正例余弦边际 +0.024），但纯内容轨排序几乎无效（R@20=0.0006） | ✅ 机制 PASS / 排序用途无效 |
| **M1 RRF 融合** | **等权 RRF 反而拉低 R@20（-27%）；高 CF 权重仅追平单轨，无增益**（best +0.25% < +0.5% 判据） | ❌ **关闭**（诚实收口） |

**一句话**：M3 证明多模态画像"可构造且含信号"，M1 证明"排名层融合在本数据无边际贡献"——内容轨（纯多模态余弦）不携带 CF 排序所需的互补信号，与 E15-TF 结论（真实互补信号 < 噪声地板）同构。

## 1. M3：e_u 多模态用户画像（机制验证 PASS）

### 实现
```
e_u = L2(mean(L2(CLIP ⊕ SBERT) of user's train items))
     img 部分: 4096 维图像特征均值
     txt 部分: 384 维文本特征均值
     cat 部分: 4480 维 concat 均值 ← 一致性验证与内容轨排序用
```
产物：`m3_eu_profiles.npz`（uid2idx + eu_img/eu_txt/eu_cat + train_items 排除清单，784MB）

### 一致性验证（held-out 信号）
| 指标 | 值 |
|---|---|
| mean_cos(画像 vs test 正例) | 0.2436 |
| mean_cos(画像 vs 随机物品) | 0.2197 |
| **正例边际** | **+0.0239**（>0，画像捕获了真实偏好） |

### 内容轨单独排序（对照组）
- content-only R@20 = **0.0006**（几乎为 0）
- **解读**：画像余弦能分辨"偏好 vs 随机"，但在 18357 物品的全库排序里，top-20 几乎全是噪声——CF 数据的主导信号来自交互图结构（用户偏好协同），不是内容特征相似度。这与 E15 的"真实互补信号低于噪声地板"完全一致。

## 2. M1：RRF 双轨融合（排名层融合，否证关闭）

### 设置
- 轨 1（CF）：LightGCN++（fc0.8 冻结融合 + pr32 投影刷新）最终嵌入，sigmoid(U·I^T) 排序，排除 train 交互
- 轨 2（内容）：e_u 画像余弦排序（M3 产物），排除 train 交互
- 融合：`S_RRF = w_cf·1/(k+rank_cf) + 1/(k+rank_emb)`，k∈{40,60,100} × w_cf∈{1,2,4,8}（MMEACR 默认 w 等权=1，k=60）
- 指标：R@20 / N@20，35598 测试用户全量

### 结果

| 配置 | R@20 | N@20 | vs CF only |
|---|---|---|---|
| **CF only** | **0.0902** | 0.0457 | — |
| Content only | 0.0081 | 0.0045 | -91% |
| RRF k60 w1.0（MMEACR 默认等权） | 0.0655 | 0.0297 | **-27%** ❌ |
| RRF k40 w2.0 | 0.0903 | 0.0451 | +0.1% |
| RRF k100 w4.0（best） | 0.0905 | 0.0449 | **+0.25%** |
| RRF k60 w8.0 | 0.0904 | 0.0457 | +0.2% |

### 分析（为什么否证）
1. **等权稀释**：内容轨 top-20 几乎全是噪声（单轨 R@20=0.008），等权 RRF 把噪声物品抬进融合排名，挤掉 CF 轨的真正例 → R@20 从 0.090 跌到 0.066。
2. **高 CF 权重只追平**：w_cf≥2 时内容轨噪声贡献被压低，融合≈单轨（0.0902→0.0905），**没有任何"融合增益"**——内容轨没提供 CF 轨缺失的有效信号。
3. **与 E15 同构**：MMEACR 的 RRF 在真实数据失效的根因与 E15-TF 一致——合成体制（GME 多模态嵌入 + LLM 推理轨）下双轨各有强信号，而项目真实数据（CLIP/SBERT 余弦）的内容轨信号低于噪声地板。

### 判定
按 `docs/mmeacr_experiment_design.md` M1 判据（融合后 R@20 ≥ max(单轨) + 0.5%）：**+0.25% < +0.5% → M1 关闭**。记录"排名层融合在本数据无边际贡献"，G 组若上 GPU 可用 LLM 排序轨重试（M4），但内容相似度轨不再投入。

## 3. 对后续实验的影响（更新路线）

| 原计划 | 调整 |
|---|---|
| M1 RRF 融合（P0 最优先） | ❌ 关闭（内容轨无信号，等权稀释，高权追平） |
| M3 e_u 画像（P1.5） | ✅ 画像可构造且含信号（+0.024 边际），但**不作为排序轨**；转向 M2 的属性记忆锚点/一致性监督用途 |
| **M2 属性引导记忆** | ⬆️ **升为唯一核心线**：e_u 画像不再做 RRF 轨，改作属性记忆的用户锚（A2-2 输入），用真实 next-item 标签强化-反思 |
| M4 LLM 推理轨评估 | 保留待 GPU：DeepSeek 排序轨可能是唯一有希望的第二轨（若成本允许） |

**关键教训（写入红线）**：在 CF 主导的数据上，"内容相似度"作为排序轨不成立——后续任何"双轨融合"主张必须先验证轨 2 的**单轨有效性**（R@20 显著 > 0），否则等权融合必然稀释。此条与 E15 数据层结论互证。
