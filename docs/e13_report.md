## 4. 分析

**4.1 同预算单变量对照（E11 vs E13）—— 深度是否抬顶？**  
E11（nl2@EP=100）= 0.09039，E13（nl4@EP=100）= 0.090897，**仅 +0.56%（+0.000507）**。  
按 E12 报告口径（当时 0.09071 vs 0.09039 的 +0.00032 记为 0.6σ），E13 的 +0.000507 约为 **~0.96σ**，仍远低于 1.96σ（p<0.05）显著性门槛。→ **深度在同等算力下未显著抬高天花板。**

**4.2 深度 + 训练时长（E12 vs E13）—— 加 epoch 还有用吗？**  
E12（nl4@EP=50）= 0.09071，E13（nl4@EP=100）= 0.090897，**EP 翻倍仅 +0.21%（+0.00019）**。  
nl4 在 EP=50 已基本收敛，EP=100 是边际收益极低的长尾。

**4.3 峰值可复现性（最强证据）—— 最优 epoch 是 seed 内禀的**

- seed2024：E12 与 E13 **同为 ep40 取峰 = 0.09087**；
- seed2026：E12 与 E13 **同为 ep45 取峰 = 0.09129**；
- 同一 seed 在「允许 EP=50」与「允许 EP=100」两种预算下，命中**完全一致**的最优 epoch 与几乎一致的峰值。

→ 说明：**最优解由 seed 的数据/初始化内禀决定，而非由「最大训练预算」决定**。把 EP 从 50 拉到 100 不会让模型越过它本就在 ep40/45 抵达的峰——只是多了无用的算力消耗。

**4.4 深度轴的真实收益边界**  
深度带来的全部增益 ≈ E11→E12 的 +0.32%（EP=50）~ E11→E13 的 +0.56%（EP=100）。这部分增益在 **EP=50 已基本实现**，EP=100 不再贡献。结论：**深度是一个「更快/更稳地抵达同一天花板」的效率杠杆，而非「抬高天花板」的容量杠杆。**

## 5. 判定（按既定判据）

> 判据：nl4@EP=100 均值 **≥0.0920** → 深度抬顶（深度轴继续）；**0.0904–0.0912** → 与 E11 无显著差异，深度仅换效率，深度轴结案转 E7/E10；**<0.09039** → 深度无效，同转 E7/E10。

**E13 均值 = 0.090897 ∈ [0.0904, 0.0912]** → 落入「与 E11 无显著差异」区间。

### ✅ 结论：深度仅换效率、不换上限，深度轴结案。算力转投 E7 / E10。

- 深度（nl2→nl4）确实给出小幅、稳定、可复现的正增益（+0.3%~0.6%），但**全部增益在 EP=50 已兑现**，EP=100 零增量；
- 最佳单 run（0.09128606）与 E12 完全相同，证明没有「更深/更久才能解锁的更高峰」；
- 因此继续加深（nl6，过平滑已在 E12 实证）、加大 epoch、加大 mm_reg 均**无意义**。

## 6. 下一步实验计划

### P0 — 深度轴正式结案（本期定论）

- 锁定结论：**nl4 / c=0.8 冻结 / pr32 / EP=50 即甜点**（EP=100 不增收益，算力浪费）。
- **明确不做**：
  - ❌ **nl6**（E12 已证 nl5 即过平滑回落起点，nl6 只会更差）；
  - ❌ **加大 mm_reg**（E3 已证伪：加大正则不涨点、反而压低）；
  - ❌ **开启 mm_eval_fresh**（口径/稳定性问题，历史实证不显著）。

### P1 — E7：mm_temp 温度扫描（新基座 nl4）

- 动机：c 已冻结在 0.8，但多模态对齐的「温度」维度（softmax 软对齐锐度）尚未探。深度轴饱和说明瓶颈**不在模型容量**，温度/对齐锐度是更可能的可调杠杆。
- 设计：`--mm_temp` 扫描（如 {0.5, 1.0, 2.0}），固定 nl4/fc0.8/pr32/mm_reg=0.001，EP=50，3 seed。
- 预期：若某温度显著 > 0.0913，则对齐质量（而非深度）是天花板来源。

### P2 — E10：真实多模态特征（疑为真瓶颈）

- 动机：E11→E13 无论如何加深度/加 epoch，R@20 始终卡在 ~0.0909。模型容量已冗余，**输入特征质量**很可能是真瓶颈。

- 预期：若真实特征显著抬点 → 瓶颈在特征工程，深度/对齐 tuning 均退居次位。
