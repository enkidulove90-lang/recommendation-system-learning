## 0. 口径定义（防误用铁律）

本文所有 Recall@20 数值采用以下口径，**跨实验对比必须同口径**：

| 口径项 | 定义 |
|---|---|
| **best R@20** | 日志尾部 `'Epoch': 'best'` 行的 `Recall@20` 字段；**两行 best 时，首行口径 = 判据对照值**（A/T 判据实证值即如此），次行作 max 审计备查 |
| **E15 判据** | 同 seed 下 TF 组须同时 > A 组 且 > T 组（首行口径）：seed42 需 >0.0408/0.0361，seed2025 需 >0.0377/0.0393 |
| **E12/E13（idea2 深度轴）** | 日志 `[TEST]` 字典 `recall` 数组第 0 位，取最优 test epoch |
| **NLGCL（P1，lastfm）** | R@20 同源 best test，同 seed 配对比较 |
| **E1 强制融合（idea2）** | 与 baseline（0.0842）同 seed 配对增益，`aggregate_idea2.py` 配对聚合 |

> ⚠️ **max 口径审计（2026-08-20 核对日志）**：A/T 判据值实为两行 best 的 **max**（A_s25=0.0377 为次行、T_s25=0.0393 为次行）。若 TF 亦取 max：seed42=max(0.0379,0.0393)=**0.0393 < A(0.0408) 仍 FAIL**；seed2025=max(0.0376,0.0406)=**0.0406 > A(0.0377)/T(0.0393) 单 seed PASS**。→ **「双 seed 同时压过」判据在首行、max 任意口径下均不成立 → 否证结论对口径选择稳健**；但 seed2025 的 max 口径 PASS 说明互补路由在部分 seed 上有微弱正向信号，如实记录于 §4。

## 1. 一句话结论

**观点②「syn 互补信号帮推荐」在真实多模态推荐中否证（E15-TF 双 seed FAIL）。** PRISM 的 synergy 损失设计（L_syn 可解释分解 + 互补增益）经 E14 → E14-bis → E14-ter → E15-TF **四连否决**，机制层（L_syn 结构阻断）与数据层（真实互补信号 < 噪声地板）均不成立。PRISM 收敛为**多模态融合正则器**；对 LightGCN++ 的**实证推荐增益 PASS 仅 NLGCL**（+11.6% 相对）。E16/E17/E18、G1/G5 关闭。

## 2. 已做实验全景（做什么 / 结果 / 成败原因）

### 2.1 PASS 部分（实证增益成立）

#### ✅ P1 · NLGCL 层间自然对比损失（idea4）—— 唯一推荐增益 PASS

| 项 | 内容 |
|---|---|
| **做了什么** | 在 LightGCN++ 上接 NLGCL 层间对比损失（纯 loss 插件 ~30 行）：锚点 = 第 l 层节点嵌入，正样本 = 第 l+1 层一阶邻居，负样本 = 非邻居异构/同构节点；λ 联合主损失 |
| **实验结果** | lastfm（seed2024）：R@20 **0.2401 → 0.2680（+11.6% 相对）**，N@20 0.2354 → 0.2579 |
| **为什么成功** | ① 对比视图**免增强**——层间传播天然构成正样本对，无需额外数据变换；② 纯 loss 插件不引入新参数、不改图结构，训练稳定；③ 层间邻居关系是 CF 信号的**直接监督**，与 BPR 目标同向互补，无目标冲突 |
| **可复用性** | 作为后续所有实验的增强基线；与 PRISM 的 E18 联合原设计已随 E15 取消，但 NLGCL 本身独立有效 |

#### ✅ E1 · idea2 强制融合消融（机制验证 PASS，非最终模块）

| 项 | 内容 |
|---|---|
| **做了什么** | 修复尺度失配 + 梯度饥饿后，用 `--force_c` 冻结融合系数 c∈{0.3,0.8,1.0} 做消融，判定"特征是否有用" |
| **实验结果** | 3 seed 最优 epoch：fc0.3 → 0.08507（+1.0%）、**fc0.8 → 0.08798（+4.5%，最优）**、fc1.0 → 0.08719（+3.6%），均 > baseline 0.0842 |
| **为什么成功** | 证明真实多模态特征**包含推荐信号**（c=0.8 优于 c=0 的自由塌缩），且**全局最优在 c≈0.8**——特征有效，问题出在"模型自己学不到这个最优" |
| **性质** | 这是**机制验证**（特征有用的阳性对照），不是可训练模块；它直接引出 E6 硬约束预算方案（`mean(c)≈0.8`）作为唯一可行机制 |

#### ✅ E12/E13 · idea2 深度轴扫描（效率杠杆 PASS，容量不抬顶）

| 项 | 内容 |
|---|---|
| **做了什么** | amazon-baby-mmssl 上扫描 n_layers∈{3,4,5} × EP∈{20,50,100}，3 seed |
| **实验结果** | nl4@EP=100 均值 **0.090897** vs E11（nl2@EP=100）=0.09039（+0.56%）；nl4@EP=50 即达 0.09071，EP 翻倍仅 +0.21%；同一 seed 在 EP=50/100 命中**完全一致的最优 epoch**（seed2024=ep40、seed2026=ep45） |
| **为什么成功/结案** | 深度是「更快更稳抵达同一天花板」的**效率杠杆**，不是「抬高天花板」的容量杠杆；最优解由 seed 内禀决定而非训练预算 → 深度轴结案，算力转真实特征/模块集成 |

### 2.2 FAIL 部分（机制或数据层否定）

#### ❌ E14 · 合成 PID 正确性探针（主证闸门 FAIL）

| 项 | 内容 |
|---|---|
| **做了什么** | 构造协同真值已知的合成图文（Unq/Red/Syn 用 XOR/乘积编码），训 PRISM MoE（4 专家 + 3 交互损失 + AFL），线性探针检验 syn 专家能否解码真值协同 |
| **实验结果** | AFL 路由权重随 w_syn 正确上升（0.074→0.201，路由对），但 **syn 专家线性探针 R² 恒平 0.147**（基线 fused 为 0.15→0.37）——syn 专家内容学错 |
| **为什么失败** | L_syn 只做「几何 decorrelation」（让 syn 远离单模态残缺版），**未锚定真值**——syn 专家可以学任意正交方向而不受惩罚 |

#### ❌ E14-bis · 真值锚定干预（机制缺陷 FAIL）

| 项 | 内容 |
|---|---|
| **做了什么** | 给 syn 专家加真值 c_syn 重建辅助损失（MSE→cos 量纲修正，λ 扫 1→10），重测探针 |
| **实验结果** | 纯锚定对照 cos=0.43 → **带 L_syn 即跌至 0.27**，λ=10（L_syn 的 20 倍）仍卡 0.273；syn-R² 仅 0.155 |
| **为什么失败** | **L_syn 机制性阻止 syn 对齐真值**：强制「远离单模态残缺版」的几何约束在优化中占主导，把 syn 锁在与 c_syn 正交的子空间；锚定梯度被结构抵消（非简单 λ 竞争）。排除量纲/容量/梯度断四类实现嫌疑 → **确诊机制缺陷** |

#### ❌ E14-ter · 显式互补损失（本体 FAIL，ter_free 合成胜出）

| 项 | 内容 |
|---|---|
| **做了什么** | 加显式互补损失 L_comp=MSE(comp_head(syn_⊥), y_proxy)，含 L_syn 与关 L_syn 双变体 |
| **实验结果** | 带 L_syn：R@20=**0.1817 < uni 0.2559** ❌；**关 L_syn（ter_free）：0.3221 > uni，syn_probe_R2=0.215** ✅ |
| **为什么失败/成功** | 根因：**乘积型 c_syn 与单模态相关**，强制 syn⊥uni 后 syn_⊥ 承载不了 c_syn → L_syn 同时是「可解释分解」+「互补增益」的阻断点；去掉 L_syn 后 syn 自由、可部分对齐 E 方向，互补路由才生效 → **ter_free 成为 E15-TF 的设计依据** |

#### ❌ E15-TF · 真实体制裁决（用户拍板变体，最终否证）

| 项 | 内容 |
|---|---|
| **做了什么** | 真实 amazon-baby-mmssl + SASRec，TF 组 = 关 L_syn + 互补路由（λ_comp=0.1），对应合成 ter_free；2 seed（42/2025）500-epoch 预算，patience=10 早停 |
| **实验结果** | seed42：**0.0379**（>T 0.0361 ✅ <A 0.0408 ❌）；seed2025：**0.0376**（<A 0.0377 ❌ 差 0.0001、<T 0.0393 ❌）。双 seed 首行口径均不压；**max 口径下 seed2025（0.0406）单 seed PASS，seed42（0.0393）仍 FAIL → 「双 seed 同时压过」任何口径不成立** |
| **为什么失败** | ① 数据层：真实下一 item 监督中**互补信号低于噪声地板**——单模态特征已编码绝大部分下一 item 信息，合成体制的强可分离 c_syn 不存在于真实数据；② 机制层（合成→真实迁移失败）：ter_free 在合成胜出（0.3221）是"构造的协同"产物，真实无此结构；③ 早停证据：seed2025 峰值 0.0376 出现在 ep3，其后 10 epoch 再未触达，属噪声级差距 |
| **结论** | **观点②真实体制否证。** PRISM 集成核心卖点（可解释协同分解 + synergy 增益）不成立 |

#### ❌ idea1 · 自适应传播（Oracle 上限不足，放弃）

| 项 | 内容 |
|---|---|
| **做了什么** | P2 Oracle 实验：L=4 逐用户选最优层 g\*_u 测上限 |
| **实验结果** | R@20 = 0.2448 vs 固定层 0.2401 → **+1.96% < 3% 阈值** |
| **为什么失败** | 不同节点对传播阶数的需求差异很小，自适应上限收益不足以支撑复杂度（改 computer() + 注意力参数）；按设计规则放弃，转投 idea3/idea4 |

#### ❌ idea2 · 学习型软门控（BPR 收缩，机制死路）

| 项 | 内容 |
|---|---|
| **做了什么** | v0→v3 三版修复（尺度失配 → 梯度饥饿 → 混合梯度路径）后，conf_mlp 软门控仍学不动 |
| **实验结果** | v3 后 conf_mean 仍塌缩（0.169→0.046）；E2（mm_conf_reg=0）决定性证据：**c 照样塌到 0.005**，且此时 R@20 单调升 0.0768→0.0852 |
| **为什么失败** | **BPR 梯度局部偏好把多模态贡献收缩到 0**（纯 ID 信号短期更干净），软惩罚本质打不过 BPR 收缩——不是系数没调好，是目标冲突；全局最优（c≈0.8）模型自己走不到 → 学习型软门控判死，转 E6 硬约束预算 |

## 3. E14→E15 证据链（四连否，同一根因）

```
E14 (合成探针)      syn R² 恒平 0.147      → L_syn 未锚真值，syn 学任意正交方向
   ↓ 加真值锚定
E14-bis (锚定干预)  带 L_syn 即 cos 0.27    → L_syn 机制性阻断，锚定救不回
   ↓ 改显式互补损失
E14-ter (互补损失)  带 L_syn R@20=0.18<uni   → L_syn 同时阻断分解+互补；ter_free 合成胜出
   ↓ 真实体制（唯一可能证成观点②的变体）
E15-TF (真实裁决)   双 seed FAIL            → 真实互补信号 < 噪声地板，观点②否证
```

**收敛判断**：根因是双重——
1. **机制层**：L_syn 的「强制 syn⊥uni」与「承载与 y 相关的互补内容」根本冲突（真实互补信息与单模态相关，不在 E^⊥ 里）；
2. **数据层**：即使绕开 L_syn（TF 组），真实下一 item 监督中互补增量信号低于噪声地板。

## 5. 结论与 PRISM 定位（收口）

1. **PRISM = 多模态融合正则器**：syn 专家作为 decorrelation/多样性正则，**不主张对推荐指标的增益贡献**；后续引用一律以本报告为准。
2. **E16/E17/E18 不执行**（依赖 E15 PASS 的前提不存在）；**G1/G5 下架**（依赖 syn 偏好信号）；G2 的 PID 归因改由 E-X2 独立承担。
3. **对 LightGCN++ 的实证增益**：NLGCL（+11.6%）为唯一 PASS 的推荐增益模块；idea2 的 E1 强制融合（+4.5%）是机制验证阳性对照，其可训练形态（E6 硬约束预算）留作 idea2 收口线。
4. **代码保留但默认关闭**：`prism_moe.py` 的 syn_anchor 接口与 SASRec 残差路由可用，λ 全置 0 即退化为 T 组行为。
