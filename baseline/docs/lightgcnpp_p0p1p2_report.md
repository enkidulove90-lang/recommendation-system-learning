# LightGCN++ 迁移改造 · P0/P1/P2 小样本测试报告

> 数据集 **lastfm**，40 epoch，种子 **2024/2025/2026**（小样本少 epoch 验证）
> 评估指标 Recall@20 / NDCG@20；环境 CPU（torch 2.13.0+cpu），需 4 个 OpenMP 变量避免段错误

## 0. 实验设置
- 模型：LightGCN++（`α=0.6, β=-0.1, γ=0.2`），dim=64, lr=1e-3, decay=1e-4
- 训练：40 epoch，topks=[20,40]，3 种子 2024/2025/2026
- P0 = L=2 基线；P1 = 注入 NLGCL 对比损失（idea4）；P2 = L=4 训练 + 逐层嵌入 Oracle 分析（idea1 决策点）
- P1 参数：cl_temp=0.1, cl_alpha=0.6(已避开与 α 命名冲突), G=2；cl_reg ∈ {5e-5, 1e-4}

## 1. P0 基线复现（LightGCN++ L=2）
| 种子 | R@20 | N@20 |
|------|------|------|
| 2024 | 0.2401 | 0.2354 |
| 2025 | 0.2399 | 0.2350 |
| 2026 | 0.2410 | 0.2361 |
| **均值** | **0.2403** | **0.2355** |

复现成功，R@20≈0.240 与 LightGCN++ 在 lastfm 上的已知水平一致。

## 2. P1 NLGCL 对比损失注入（idea4，最该先做）
| 配置 | R@20 | N@20 | 相对 P0 (R@20) |
|------|------|------|------|
| P0 基线 | 0.2403 | 0.2355 | — |
| P1 NLGCL cl_reg=5e-5 | 0.2674 | 0.2570 | **+11.3%** |
| P1 NLGCL cl_reg=1e-4 | 0.2653 | 0.2530 | +10.4% |

**结论**：NLGCL 增益远超预期——R@20 从 0.240 → 0.267（**相对 +11.3%**），
N@20 从 0.236 → 0.257（+9.1%）。比我原方案"因逐层 L2 归一化与 CL 重叠，
收益会低于论文 +6%"的谨慎预测更高，说明 lastfm 上两者互补得很好。**NLGCL 是四个 idea 里最值得先落地的，
且目前收益最高**。`cl_reg=5e-5` 略优于 `1e-4`，建议采用 5e-5。

### 3.5 idea1 决策结论
- **Oracle 增益均值 3.88% ∈ [3%, 8%) → 走轻量规则版（不做可学习/RL 版）。**
- 表C 显示所有度数桶最优层都集中在 **L=1 或 L=2**，无桶偏好 L=3/L=4；高层（L=3/L=4）普遍不如 L=1/L=2。
- 增益主要来自**少数低度用户**（度数 1-10 偏好 L=0/L=1），而中高度用户（11-50）最优就是 L=2——即 LightGCN++ 默认设置已接近最优。
- 因此 idea1 收益**中等（~4%）**，用**度数感知的轻量规则层权重** `γ_u = σ(a·log d_u + b)` 即可捕获"低度用浅层、高度用 L=2"的模式，
  无需可学习注意力或 RL（性价比低）。这同时也是 idea3 成本感知的自然接口（浅层=低成本）。
