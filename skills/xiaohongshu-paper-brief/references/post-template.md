# 小红书论文快报文本模板

```text
【{会议或期刊} {年份}｜{企业或机构}】
{趣味标题：一句问题或反直觉结论}

📌 这篇论文解决什么？
{用 1–2 句交代任务、痛点与适用边界。}

✨ 主要贡献 / 创新点
1. {贡献一：对象、机制、收益。}
2. {贡献二。}
3. {贡献三；没有则省略。}

🔧 方法论
{说明模型/系统流程和关键模块。若为综述或视角论文，说明其分析框架而非虚构算法。}

🧪 Benchmark 与数据集
- 任务：{任务}
- 数据集/基准：{数据集；没有则“原文未披露”}
- 对比方法：{基线；没有则“原文未披露”}
- 指标：{指标；没有则“原文未披露”}

⚙️ 实验条件
- 实现环境与关键设置：{模型、硬件、训练或推理设置；没有则“原文未披露”}
- 评价协议：{切分、预算、阈值等；没有则“原文未披露”}

📊 实验效果
{写“论文报告：…”；交代数据集/指标/对照和具体数值。无统一实验时写“不适用：本文未提出统一实验”。}

💡 对{目标研究或系统}的借鉴
{列 2–4 条可迁移的设计启发，并说明仍需本地数据或在线评估验证。}

📎 arXiv 链接
{arXiv URL}

💻 GitHub 链接
{official GitHub URL 或“暂无已核验官方 GitHub”}

📄 附件
原论文 PDF 已作为文件组件随草稿上传。
```

For the final JSON `body`, replace placeholders, remove unused lines, retain actual line breaks, and avoid unverified claims.
