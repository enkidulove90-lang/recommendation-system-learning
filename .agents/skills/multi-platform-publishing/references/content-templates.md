# 内容模板

## 模板 A：单篇论文深度解读

> 适用：一篇论文详细介绍。参考「符号看象限Ai」、「三无者也」。

### 标题公式

```
[会议/期刊]+[录取率/排名]｜[一句话卖点]+[先河/首次/SOTA/突破]
```

示例：
- `ICML26Top2.2%｜VLA隐式思维链先河`
- `ICLR2026中南大学｜ConCM持续学习新框架`

标题关键词库：`先河` `首次` `突破` `SOTA` `新范式` `开源` `即插即用` `Oral` `Spotlight`

### 小红书正文模板

```
🎓 [1段，3-5句：问题背景+痛点，口语化制造冲突]
   "当前XX模型普遍面临一个尴尬：..."
   "[方法名]算是第一个系统性把「XX」引入XX的工作。"

✨ [2-3句：核心亮点，用数字制造冲击]
   "比SOTA强出14%？"
   "一句话：又准又快。"

🧠 [3-5个bullet：方法拆解，技术深度+可读性]
   "隐式CoT：把视觉、点云压缩成连续隐序列..."
   "MoT双系统：低频Reason Expert做时空推理..."

📊 [1-2句：实验效果，只列最亮眼的数字]
   "Amazon Fashion域：N@1 ↑45.45%，推理时间 ↓16%。"

💡 [3个可探索的方向，给读者「带走的价值」]
   方向一：[一句话描述]
   方向二：[一句话描述]
   方向三：[一句话描述]

arxiv 🔗：https://arxiv.org/abs/XXXX.XXXXX
github 🔗：https://github.com/xxx/xxx（如有）
📎 原文 PDF：https://arxiv.org/pdf/XXXX.XXXXX
```

### 公众号正文模板

```markdown
# {标题}

## 背景

{300字：当前领域痛点，为什么需要这篇论文的方法}

## 方法

{500字：核心方法拆解，保留关键英文术语+中文含义}
- 模块1：...
- 模块2：...
- 训练策略：...

## 实验

{300字：主要实验结果}
- 数据集：{dataset}
- 基线对比：{baseline}
- 核心指标提升：{metrics}

## 局限性

{200字：论文自述局限+客观分析}

## 实践启发

{200字：3个可落地的方向}
1. {方向一}
2. {方向二}
3. {方向三}

## 参考文献

- 论文：{paper_url}
- PDF：{pdf_url}
- 代码：{code_url or "暂无官方代码"}

> 图表摘自论文，仅作学术解读。
```

## 模板 B：综述/多篇汇总

> 适用：综述论文、会议中稿汇总、领域方向盘点。

### 标题公式

```
[缩写/领域]｜[中文描述]+[综述/汇总/盘点/一览]
```

示例：
- `LLM4CO｜大模型求解组合优化问题综述`
- `ICML26 Agent中稿汇总｜Tool-Use + Multi-Agent 一文打尽`

### 小红书综述模板

```
📖 [1-2段：领域背景+为什么这个方向重要]
   "组合优化是运筹学与AI的交叉核心问题..."
   "本文系统梳理了XX篇论文，按XX个维度分类。"

🗂 分类体系
   • 类别1（XX篇）：[一句话描述]
     - 代表工作：[论文名] ([会议], 2026) — [一句话亮点]
   • 类别2（XX篇）：[一句话描述]

🧩 方法论对比
   | 方法路线 | 代表工作 | 优势 | 局限 |
   |---------|---------|------|------|
   | LLM as Optimizer | OPRO | 零样本泛化 | 精度低 |

🔮 可探索的研究方向（必选板块）
   方向一：[为什么值得做+当前瓶颈+建议切入点]
   方向二：...
   方向三：...

📚 参考论文列表
   [1] [标题]. [会议], 2026. arxiv 🔗
   [2] ...

💻 GitHub 仓库
   • https://github.com/xxx — [简介]

📎 综述原文 PDF
```

## 语言风格对照

| ❌ 平庸（论文翻译腔） | ✅ 爆款（中文互联网风格） |
|---------------------|--------------------------|
| 提出XX框架，通过双轨... | 现有LLM Agent有个尴尬的问题：... |
| 在三个数据集上显著超越基线 | 比XX高出45.45%？直接拉满 |
| 采用属性引导的机制 | 让Agent学会「做对了就记住，做错了就反思」 |
| 实现性能提升 | 又准又快，推理时间还降了16% |
| 为XX提供新范式 | 推荐Agent终于能「看见」商品了 |

## 通用格式规则

| 要素 | 做法 | 效果 |
|------|------|------|
| Emoji 段落标题 | 🎓 ✨ 🧠 📊 💡 🔮 📚 | 视觉层次 |
| 段落间空行 | `\n\n` | 避免拥挤 |
| 论文链接 | `arxiv 🔗：https://...` | 可长按复制 |
| 话题标签 | `--topic "推荐系统"` CLI 参数 | 蓝色可点击 |
| 要点列表 | `•` 或数字开头 | 结构化 |
| 数字冲击 | `↑45.45%` `14倍` `Top 2.2%` | 制造记忆点 |
| 方向/展望 | 模板A 3个，模板B 3-5个 | 提高收藏率 |

## 图片排版

- 竖版 2550×3300 或 2100×2996，适配手机全屏
- 重新排版的信息图，不要直接截 PDF
- 每张图配一句话说明，形成「看图说话」
- 优先：架构图 → 对比表 → 效果图 → Case Study
- 避免：公式密集图、文字截图、小尺寸图标
