# 3886. 可排序整数求和

话题标签: array, math, enumeration, sorting

## 思路

题目要求我们把数组切成若干个长度相同的连续块（块长 k 必须是 n 的因数），每块内部可以任意循环移动（左移或右移），问哪些 k 能拼出整个数组的非递减顺序。

核心观察有两条：

1. **块内只能循环移动，不能任意重排。** 一个块循环移动后，元素之间的相对循环顺序不变。所以块内元素必须本身就能通过一次「旋转」变成非递减，否则这个 k 直接不成立。长度为 k 的块能旋转成有序，等价于块内最多只有一个「下降点」（即 `a[i] > a[i+1]` 的位置）；且若存在下降点，旋转后的最小值是下降点后一个元素，最大值是下降点处的元素。

2. **块与块之间必须整体有序。** 每块旋转后，其最小值必须不小于前一块旋转后的最大值，否则无法拼成全局非递减。

有了这两条，只需对 n 的每个因数 k，逐块检查即可。为了快速判断「块内下降点个数」，预处理整个数组所有下降点的下标列表 `drop_id`，用二分查找定位每个块 `[start, end)` 内的下降点，因为块内下降点只可能出现在下标 `start` 到 `end-2` 之间。

## 解题过程

1. 预处理 `drop_id`：记录所有满足 `nums[i] > nums[i+1]` 的下标 i。
2. 枚举 n 的所有因数（用 `sqrt(n)` 枚举，成对加入）。
3. 对每个因数 k，按块遍历：
   - 用 `bisect_left(drop_id, start)` 找到块内第一个可能的下降点位置。
   - 若该下降点下标 `<= end-2`，说明块内有下降点，计数加一；再看下一个下降点是否也 `<= end-2`，若是则块内下降点超过一个，该 k 不可行，直接跳出。
   - 块内下降点数为 1 时，检查旋转后是否有序：需要 `nums[end-1] <= nums[start]`（否则旋转后首元素仍大于末元素，无法非递减）。旋转后的最小值为 `nums[first_drop_idx+1]`，最大值为 `nums[first_drop_idx]`。
   - 块内下降点数为 0 时，块本身已有序，最小值为 `nums[start]`，最大值为 `nums[end-1]`。
   - 用 `prev_block_max` 记录前一块的最大值，若当前块最小值小于它，则 k 不可行。
4. 所有块都通过，则把 k 累加到答案。

小例子：`nums = [3,1,2]`，n=3，因数为 1 和 3，`drop_id = [0]`（因为 3>1）。
- k=1：每块只含一个元素，块内不可能有下降点，每块的 min 与 max 就是那个元素本身。三块依次为 3、1、2，走到第二块时 `cur_min=1` 小于前一块的 `prev_block_max=3`，判定失败，k=1 不可行。
- k=3：整个数组是一块。块内只有一个下降点（下标 0），且 `nums[2]=2 <= nums[0]=3` 成立，说明旋转后确实非递减；旋转后 min = `nums[1]` = 1，max = `nums[0]` = 3。可行。
- 答案是 3。

## 复杂度

时间复杂度：O(n·log n·d(n))，其中 d(n) 是 n 的因数个数。枚举因数 O(√n)；对每个因数 k 遍历 n/k 个块，每块一次 O(log n) 的二分定位下降点，取 k=1 得上界 O(n·log n·d(n))。n ≤ 10^5 时因数个数很少，本次提交实测 161 ms。
空间复杂度：O(n)，用于存储下降点下标列表 `drop_id`（最多 n-1 个）。

## Code

```python3
import bisect

class Solution:
    def sortableIntegers(self, nums: list[int]) -> int:
        n = len(nums)
        if n==0: return 0
        drop_id = [i for i in range(n-1) if nums[i]>nums[i+1]]

        divisors = []
        for i in range(1,int(n**0.5 + 1)):
            if n%i==0:
                divisors.append(i)
                if(i*i!=n):
                    divisors.append(n//i)

        qelv = nums

        totalsum = 0

        for k in divisors:
            is_k_sortable = True
            prev_block_max = -float('inf')

            for start in range(0,n,k):
                end = start + k

                idx_in_drops = bisect.bisect_left(drop_id,start)

                cnt = 0
                first_drop_idx = -1
                if idx_in_drops<len(drop_id) and drop_id[idx_in_drops] <= end - 2:
                    cnt = 1
                    first_drop_idx = drop_id[idx_in_drops]
                    if idx_in_drops +1 <len(drop_id) and drop_id[idx_in_drops+1]<=end-2:
                        cnt = 2
                if cnt>1:
                    is_k_sortable = False
                    break
                if cnt==1:
                    if qelv[end-1]>qelv[start]:
                        is_k_sortable = False
                        break
                    cur_min = qelv[first_drop_idx + 1]
                    cur_max = qelv[first_drop_idx]
                else:
                    cur_min = qelv[start]
                    cur_max = qelv[end-1]
                if cur_min<prev_block_max:
                    is_k_sortable = False
                    break
                prev_block_max = cur_max
                
            if is_k_sortable:
                totalsum+=k
        return totalsum
                
```

### C++

```cpp
#include <vector>
#include <cmath>
#include <algorithm>
#include <limits>

class Solution {
public:
    int sortableIntegers(std::vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        std::vector<int> drop_id;
        for (int i = 0; i < n - 1; i++) {
            if (nums[i] > nums[i + 1]) drop_id.push_back(i);
        }

        std::vector<int> divisors;
        for (int i = 1; i < (int)(std::sqrt((double)n) + 1); i++) {
            if (n % i == 0) {
                divisors.push_back(i);
                if (i * i != n) {
                    divisors.push_back(n / i);
                }
            }
        }

        std::vector<int>& qelv = nums;

        int totalsum = 0;

        for (int k : divisors) {
            bool is_k_sortable = true;
            double prev_block_max = -std::numeric_limits<double>::infinity();

            for (int start = 0; start < n; start += k) {
                int end = start + k;

                int idx_in_drops = std::lower_bound(drop_id.begin(), drop_id.end(), start) - drop_id.begin();

                int cnt = 0;
                int first_drop_idx = -1;
                if (idx_in_drops < (int)drop_id.size() && drop_id[idx_in_drops] <= end - 2) {
                    cnt = 1;
                    first_drop_idx = drop_id[idx_in_drops];
                    if (idx_in_drops + 1 < (int)drop_id.size() && drop_id[idx_in_drops + 1] <= end - 2) {
                        cnt = 2;
                    }
                }
                if (cnt > 1) {
                    is_k_sortable = false;
                    break;
                }
                int cur_min, cur_max;
                if (cnt == 1) {
                    if (qelv[end - 1] > qelv[start]) {
                        is_k_sortable = false;
                        break;
                    }
                    cur_min = qelv[first_drop_idx + 1];
                    cur_max = qelv[first_drop_idx];
                } else {
                    cur_min = qelv[start];
                    cur_max = qelv[end - 1];
                }
                if (cur_min < prev_block_max) {
                    is_k_sortable = false;
                    break;
                }
                prev_block_max = cur_max;
            }

            if (is_k_sortable) {
                totalsum += k;
            }
        }
        return totalsum;
    }
};
```
