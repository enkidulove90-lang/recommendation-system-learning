# 3963. 构造恰好一条路径的网格

话题标签: （无）

## 思路

题目要求构造一个网格，让从左上角 (0, 0) 到右下角 (m-1, n-1) 的路径（只能向右或向下走）恰好只有一条。

核心观察是：如果整个网格全是空地，那么路径数量会非常多（组合数级别）。要压到恰好一条，最直接的办法是把"多余的分支"全部用障碍堵死，只留下一条通道。

一个简洁的构造是：**第一行全部留空，其余每一行只在最右一列留空，左边全部填障碍**。这样第一行可以一路向右走到右上角，然后只能沿着最右一列一路向下走到终点。途中其他行左侧都是障碍，无法从第一行中途向下拐，也没有别的岔路，所以路径唯一。

这种构造对所有 m、n 都成立，包括 m = 1（此时没有额外的行）和 n = 1（此时每行只剩一个格子，`'#' * 0 + '.'` 就是 `'.'`）的边界情况。

## 解题过程

1. 第一行：生成 `n` 个 `'.'`，即 `'.' * n`，保证从 (0, 0) 能一路向右走到 (0, n-1)。
2. 其余 `m - 1` 行：每行前 `n - 1` 个格子填 `'#'`，最后一格填 `'.'`，即 `'#' * (n - 1) + '.'`。这样每一行只有最右列可走。
3. 把第一行和后面 `m - 1` 行拼起来返回。

以 m = 2, n = 3 为例：

- 第一行：`...`
- 第二行：`##.`
- 结果网格：
  ```
  ...
  ##.
  ```
  路径只能是 (0,0)→(0,1)→(0,2)→(1,2)，唯一。

以 m = 3, n = 3 为例：

- 第一行：`...`
- 后两行：`##.`、`##.`
- 结果：
  ```
  ...
  ##.
  ##.
  ```
  路径 (0,0)→(0,1)→(0,2)→(1,2)→(2,2)，唯一。

当 n = 1 时，`'#' * 0` 是空串，每行就是 `'.'`，整个网格是一列，只有一条向下的路径，同样正确。

## 复杂度

时间复杂度：O(m × n)，需要生成 m × n 个字符。
空间复杂度：O(m × n)，存储返回的网格本身（不计返回值则为 O(1)）。

## Code

```python3
class Solution:
    def createGrid(self, m: int, n: int) -> list[str]:
        return ['.' * n] + ['#' * (n - 1) + '.'] * (m - 1)
```
## Code（其他语言版本，编辑器中为可切换 tab）

### C++

```cpp
class Solution {
public:
    vector<string> createGrid(int m, int n) {
        vector<string> res;
        res.push_back(string(n, '.'));
        for (int i = 0; i < m - 1; ++i) {
            res.push_back(string(n - 1, '#') + ".");
        }
        return res;
    }
};
```
