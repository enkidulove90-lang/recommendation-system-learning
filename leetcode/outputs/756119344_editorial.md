# 3863. 将一个字符串排序的最小操作次数

话题标签: string

## 思路

题目要求把字符串排成非降序，每次只能挑一个**真子串**（不能是整个字符串）做升序排序。排序只会把字符在子串内部重排，不会把字符移出子串，所以每个字符能去的位置受限于它所在子串的范围。

关键观察是结果的取值范围很小。把字符串看成已经排好序的目标串，如果原串本身有序，答案是 0。否则答案只可能是 1、2、3 或 -1：

- 长度 2 时，唯一能选的子串只能是长度为 1 的单个字符，排序不改变任何东西，所以只要原串无序就无解，返回 -1。
- 长度大于 2 时，若最小字符在开头：把**去掉开头后的整个后缀**排序——开头本来就是全局最小，后缀排成升序后整串自然有序；同理，若最大字符在末尾：把去掉末尾的整个前缀排序即可。都是一次操作。（注意操作不能选整个串，所以要留下至少一个字符在外面。）
- 若最小字符或最大字符出现在中间：两次解决。以最小字符为例，设它某次出现在位置 i（i ≤ n-2）：先排序前缀 `s[0..i]`，最小字符作为全局最小会落到开头；再排序后缀 `s[1..n-1]`，整串有序。最大字符在中间时对称：先排序含它的后缀把它压到末尾，再排序前缀。
- 剩下的唯一形态是：开头是最大字符、结尾是最小字符、中间全部严格介于两者之间（否则会落进前两种）。用三次操作构造：① 排序 `s[1..n-1]`，串变为 `mx, mi, 中间升序`；② 排序 `s[0..n-2]`，这一段里的最小字符 `mi` 被顶到开头，最大字符 `mx` 落到倒数第二位；③ 再排序 `s[1..n-1]`，整串有序。

以上分类覆盖了所有情况（0 = 已有序，-1 = 长度 2 无序），所以答案只可能是 0、1、2、3、-1，判断只需线性扫描。

## 解题过程

1. 先检查原串是否已经非降序，是则返回 0。
2. 若长度为 2，返回 -1。
3. 记 `mi` 为最小字符、`mx` 为最大字符。
4. 若 `s[0] == mi` 或 `s[-1] == mx`，返回 1。
5. 否则若在 `s[1:-1]` 中出现了 `mi` 或 `mx`，返回 2。
6. 以上都不满足，返回 3。

以 `"card"` 为例：`mi='a'`，`mx='r'`，`s[0]='c'` 不是 `mi`，`s[-1]='d'` 不是 `mx`；中间 `"ar"` 含 `mi='a'`，返回 2，与示例一致。`"gf"` 长度为 2 且无序，返回 -1。

## 复杂度

时间复杂度：O(n)，排序检查与字符扫描各一次线性遍历。
空间复杂度：O(n)，`sorted(s)` 会生成新字符串。

## Code

```python3
class Solution:
    def minOperations(self, s: str) -> int:
        if s==''.join(sorted(s)):
            return 0
        if len(s)==2:
            return -1
        mx,mi = max(s), min(s)
        if s[0]==mi or s[-1] ==mx:
            return 1
        elif any(ch==mi or ch==mx for ch in s[1:-1]):
            return 2
        return 3
```
## Code（其他语言版本，编辑器中为可切换 tab）

### C++

```cpp
class Solution {
public:
    int minOperations(string s) {
        string sorted_s = s;
        sort(sorted_s.begin(), sorted_s.end());
        if (s == sorted_s) {
            return 0;
        }
        if (s.size() == 2) {
            return -1;
        }
        char mx = *max_element(s.begin(), s.end());
        char mi = *min_element(s.begin(), s.end());
        if (s[0] == mi || s[s.size() - 1] == mx) {
            return 1;
        } else {
            bool found = false;
            for (size_t i = 1; i + 1 < s.size(); ++i) {
                if (s[i] == mi || s[i] == mx) {
                    found = true;
                    break;
                }
            }
            if (found) {
                return 2;
            }
        }
        return 3;
    }
};
```
