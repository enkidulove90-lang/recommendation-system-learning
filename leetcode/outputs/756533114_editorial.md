# 3644. 排序排列

话题标签: bit-manipulation, array

## 思路

题目给的是一个 0 到 n-1 的排列，允许交换下标 i 和 j 上的元素，前提是这两个位置上的**值**满足 `nums[i] AND nums[j] == k`，k 对所有交换都固定。要求找出能让数组排好序的最大 k。

排序后的目标状态是 `nums[i] == i`，所以先分出两类位置：已经就位的不用动，错位的元素必须通过交换回到原位。记所有错位元素的集合为 S，把它们的按位与记作 `ans = AND(S)`。答案就是 `ans`，理由分两步：`ans` 是上界，并且 `ans` 本身一定能做到。

**第一步：任何能用的 k 都必须是 ans 的子集。** 错位元素 x 终归要被换走，所以它至少要参与一次交换，每次交换都要求 `x AND y == k`。按位与的结果只会是 x 的子集（x 里为 0 的位，结果必然是 0），所以 `k & x == k`，即 k 的每个 1 位都在 x 里。这对每个错位元素都成立，于是 k 的每个 1 位都在 `ans` 里——k 取不到 `ans` 之外任何一位，数值上也就不会超过 `ans`。

**第二步：k = ans 可行。** 关键在于 `ans` 这个值一定在数组里：`ans` 是若干小于 n 的数按位与的结果，必然小于 n，而数组恰好是 0 到 n-1 的排列。同时 `ans` 是 S 中所有元素的公共子集，所以对每个错位元素 x 都有 `ans & x == ans`——也就是说元素 `ans` 和每个错位元素之间都满足交换条件。把它当成中转站：任何环都能借它周转，交换完再让它自己回到原位，环就解开了。（`ans = 0` 时同样成立：0 与任何数按位与都是 0，`k = 0` 永远能排序，这也是题目在只能取 0 时返回 0 的原因。）

**边界。** 若 `nums[0] != 0`，值 0 一定错位，而 0 与任何数按位与都是 0，`ans` 只能是 0，直接返回 0。若数组本来就有序，没有错位元素，不需要任何交换，返回 0。

## 解题过程

1. 如果 `nums[0] != 0`，说明 0 不在正确位置，任何包含 0 的交换结果都是 0，最大 k 只能是 0，直接返回 0。
2. 初始化 `ans = -1`，它作为按位与的初始值（所有位都是 1），不会影响后续结果。
3. 遍历每个下标 i 和值 x，若 `i != x` 说明该位置错位，执行 `ans &= x`，把所有错位元素按位与起来。
4. 如果数组本来就有序，循环中不会更新 `ans`，它保持 -1，最后 `max(ans, 0)` 返回 0，符合题目要求。
5. 否则返回 `ans`，即所有错位元素的按位与。

以示例 1 `nums = [0,3,2,1]` 为例：下标 1 的值是 3、下标 3 的值是 1 错位，`3 & 1 = 1`，答案为 1。示例 2 `[0,1,3,2]`：错位元素是 3 和 2，`3 & 2 = 2`，答案为 2。示例 3 `[3,2,1,0]`：`nums[0] = 3 != 0`，直接返回 0。

## 复杂度

时间复杂度：O(n)，只需遍历数组一次。
空间复杂度：O(1)，只用了常数个额外变量。

## Code

```python3
class Solution:
    def sortPermutation(self, nums: List[int]) -> int:
        ans = -1
        if nums[0]:
            return 0
        for i,x in enumerate(nums):
            if i!=x:
                ans &= x
        return max(ans,0)
```

### C++

```cpp
class Solution {
public:
    int sortPermutation(vector<int>& nums) {
        int ans = -1;
        if (nums[0]) {
            return 0;
        }
        for (int i = 0; i < nums.size(); ++i) {
            int x = nums[i];
            if (i != x) {
                ans &= x;
            }
        }
        return max(ans, 0);
    }
};
```
