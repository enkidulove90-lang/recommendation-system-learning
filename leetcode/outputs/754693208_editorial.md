# 3723. 数位平方和的最大值

话题标签: greedy, math

## 思路

题目要求构造一个恰好 `num` 位、各位数字之和恰好为 `sum` 的正整数，使得各位数字的平方和最大；若同分则取数值最大的那个，无解返回空串。

关键观察在于平方和的“性价比”。把数字 0~9 的平方列出来：0→0，1→1，2→4，3→9，4→16，5→25，6→36，7→49，8→64，9→81。可以看到每多消耗 1 点“数字和”，换成 9 能换来 81 分，换成 8 只有 64/8=8 分，换成 7 只有 49/7=7 分。也就是说，用 9 来凑数字和，单位数字和的得分最高。因此要让平方和最大，就要尽量多用 9。

那剩下的余数怎么办？如果 `sum` 不是 9 的倍数，会剩下 `r = sum % 9`（1~8）。这 1~8 点数字和必须由某一位承担，用一位数字 `r` 来放它，比拆成两个更小的数字得分更高（因为平方是凸的，合并成一位更划算），所以余数直接作为单独一位。

位数方面：用 `sum // 9` 个 9 加上可能的余数位，总共占 `len(ans)` 位。如果这个位数已经超过 `num`，说明凑不出来，返回空串；否则剩下的 `num - len(ans)` 位全部填 0，既不影响数字和（0 不贡献），也不影响平方和（0 的平方还是 0）。

至于“同分取最大整数”：把所有非零数字放在最高位、0 放在末尾，得到的数就是同位数字集合下最大的排列。而上面的构造方式（先 9、再余数、最后补 0）恰好把较大的数字排在前面——不过要注意余数 `r` 一定小于 9，所以顺序是若干个 9 后跟一个 `r`，再跟若干 0，这已经是从大到小的排列，因此得到的正是同分方案里数值最大的那个。

## 解题过程

1. 计算 `sum // 9`，得到可以放多少个 9，把它们拼成字符串前缀。
2. 计算 `r = sum % 9`。若 `r != 0`，把 `str(r)` 追加到后面（这一位承担剩余的数字和）。
3. 此时字符串长度为 `sum // 9 + (1 if sum % 9 else 0)`。用 `num` 减去这个长度得到还需要补的 0 的个数，补在末尾。
4. 检查最终字符串长度是否恰好等于 `num`。若等于，返回该字符串；否则说明需要的位数超过了 `num`（例如 `num=1, sum=10`，需要 2 位），返回空字符串。

以 `num=2, sum=3` 为例：`3//9=0`，`3%9=3`，先得到 `"3"`，再补 `2-1=1` 个 0，得到 `"30"`，长度 2，返回 `"30"`，与示例一致。

以 `num=2, sum=17` 为例：`17//9=1`，得到 `"9"`；`17%9=8`，追加得到 `"98"`；补 `2-2=0` 个 0，返回 `"98"`，与示例一致。

以 `num=1, sum=10` 为例：`10//9=1` 得到 `"9"`，`10%9=1` 追加得到 `"91"`，长度 2 大于 `num=1`，返回 `""`。

## 复杂度

时间复杂度：O(num)，字符串拼接和长度检查都与 num 成正比，构造结果本身就是 O(num) 的。
空间复杂度：O(num)，用于存放返回的字符串。

## Code

```python3
class Solution:
    def maxSumOfSquares(self, num: int, sum: int) -> str:
        ans = ""
        ans+= '9'*(sum//9)
        if sum%9:
            ans+=str(sum%9)
        ans = ans +(num-len(ans))*'0'
        return ans if len(ans)==num else ""
```

### C++

```cpp
class Solution {
public:
    string maxSumOfSquares(int num, int sum) {
        string ans = "";
        ans += string(sum / 9, '9');
        if (sum % 9) {
            ans += to_string(sum % 9);
        }
        ans = ans + string(num - ans.length(), '0');
        return ans.length() == num ? ans : "";
    }
};
```
