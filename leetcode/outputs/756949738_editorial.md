# 3619. 总价值可以被 K 整除的岛屿数目

话题标签: depth-first-search, breadth-first-search, union-find, array, matrix

## 思路

题目要求找出所有「总价值能被 k 整除」的岛屿数量。岛屿的定义是四连通（上下左右）的正整数格子。因为网格中每个格子只属于一个岛屿，所以做法很直接：遍历整个网格，遇到一个还没访问过的陆地格子，就用深度优先搜索（DFS）把整个岛屿的所有格子走一遍，边走边累加价值，同时把走过的格子标记为已访问，避免重复计算。走完一个岛屿后，判断累计的总价值能否被 k 整除，能则答案加一。

这里用「把访问过的格子改成 -1」来代替额外的 visited 数组。判断条件写成 `grid[i][j] <= 0`，这样既能跳过原本就是 0 的水域，也能跳过标记成 -1 的已访问陆地，一个条件同时处理两种情况。

复杂度上，每个格子最多被访问一次，整体是线性的，m·n 最大 10^5，完全够用。

## 解题过程

1. 记录网格的行数 `row` 和列数 `col`，准备四个方向 `(0,1),(0,-1),(1,0),(-1,0)`。
2. 定义 DFS 函数 `dfs(i, j)`：越界或 `grid[i][j] <= 0` 时直接返回；否则把当前格子的值累加到 `cur`，把格子标记为 `-1`，再对四个方向递归。
3. 双重循环遍历每个格子 `(i, j)`：先把 `cur` 清零，如果 `grid[i][j]` 非零（是未访问的陆地），调用 `dfs(i, j)` 遍历整个岛屿。
4. DFS 返回后，`cur` 就是这个岛屿的总价值，若 `cur % k == 0` 则答案 `ans` 加一。
5. 遍历结束返回 `ans`。

小例子：示例 2 中 `grid = [[3,0,3,0],[0,3,0,3],[3,0,3,0]]`，k = 3。每个 3 都与其它 3 上下左右不相邻（中间隔着 0），所以每个 3 单独构成一个岛屿，共 6 个岛屿，每个价值 3，都能被 3 整除，答案为 6。

注意 `cur` 用 `nonlocal` 声明，让内层 DFS 能修改外层循环里的变量；每进入一个新岛屿前必须把它重置为 0，否则会累加上一个岛屿的价值。

## 复杂度

时间复杂度：O(m·n)，每个格子最多被 DFS 访问一次（标记成 -1 后不会再进入），外层双重循环也是 O(m·n)。
空间复杂度：O(m·n)，最坏情况递归栈深度等于岛屿大小，比如整个网格是一整块连通陆地。

一个 Python 上的实际限制：递归深度受 `sys.getrecursionlimit()` 约束（默认 1000），而题目允许 m·n 到 10^5。如果数据出现 `1 × 100000` 这种整条连通的岛屿，这份 DFS 会抛 RecursionError（本题测试数据没有卡这一点，所以能过）。想彻底稳妥，可以在开头 `sys.setrecursionlimit(300000)`，或者把 DFS 换成显式栈的迭代写法。

## Code

```python3
class Solution:
    def countIslands(self, grid: List[List[int]], k: int) -> int:
        row,col = len(grid),len(grid[0])
        dir = (0,1),(0,-1),(1,0),(-1,0)
        cur = 0
        def dfs(i,j):
            if i<0 or j<0 or i>=row or j>=col or grid[i][j]<=0:
                return False
            nonlocal cur
            cur+=grid[i][j]
            grid[i][j]=-1
            for dx,dy in dir:
                dfs(i+dx,j+dy)
            return True
        ans = 0
        for i in range(row):
            for j in range(col):
                cur = 0
                if grid[i][j] and dfs(i,j):
                    if cur%k==0:
                        ans+=1
        return ans
```

### C++

```cpp
class Solution {
public:
    int countIslands(vector<vector<int>>& grid, int k) {
        int row = grid.size(), col = grid[0].size();
        vector<pair<int,int>> dir = {{0,1},{0,-1},{1,0},{-1,0}};
        int cur = 0;
        function<bool(int,int)> dfs = [&](int i, int j) -> bool {
            if (i < 0 || j < 0 || i >= row || j >= col || grid[i][j] <= 0) {
                return false;
            }
            cur += grid[i][j];
            grid[i][j] = -1;
            for (auto& d : dir) {
                dfs(i + d.first, j + d.second);
            }
            return true;
        };
        int ans = 0;
        for (int i = 0; i < row; i++) {
            for (int j = 0; j < col; j++) {
                cur = 0;
                if (grid[i][j] && dfs(i, j)) {
                    if (cur % k == 0) {
                        ans += 1;
                    }
                }
            }
        }
        return ans;
    }
};
```
