# 3882. 网格图中最小异或路径

话题标签: bit-manipulation, array, dynamic-programming, matrix

## 思路

题目要求从左上角走到右下角，每步只能向右或向下，路径代价是路径上所有格子值的异或和，求所有路径中最小的异或值。

关键观察是格子的取值范围：`grid[i][j] <= 1023`，也就是说每个格子的值只占 10 个二进制位。异或运算不会产生更高的位，所以任意一条路径的异或结果一定落在 `[0, 1023]` 这个区间内，一共只有 1024 种可能的取值。这个范围很小，可以直接把“异或值”本身作为状态维度。

于是用动态规划：`f[i][j][s]` 表示“能否从起点走到 `(i, j)`，使得路径异或值恰好为 `s`”。状态数最多是 `m * n * 1024`，而题目保证 `m * n <= 1000`，因此总状态量在百万级别，可以接受。转移时从 `(i, j)` 向右或向下扩展，把当前异或值和新格子的值再异或一次，标记到新位置对应的状态上。

最后只需要从小到大枚举 `s`，第一个在终点可达的 `s` 就是最小异或值。

## 解题过程

1. 建立三维布尔数组 `f`，大小为 `n * m * 1024`，全部初始化为不可达。
2. 起点状态：`f[0][0][grid[0][0]] = 1`，因为路径包含起点本身。
3. 按行、按列遍历每个格子 `(i, j)`，再枚举所有可能的异或值 `s`：
   - 若 `f[i][j][s]` 不可达则跳过；
   - 若能向下走，则 `f[i+1][j][s ^ grid[i+1][j]] = 1`；
   - 若能向右走，则 `f[i][j+1][s ^ grid[i][j+1]] = 1`。
4. 遍历结束后，从 `0` 到 `1023` 依次检查 `f[n-1][m-1][s]`，第一个为真的 `s` 即为答案。

以示例 1 为例，`grid = [[1,2],[3,4]]`：

- 起点状态为 `{1}`；
- 向右到 `(0,1)` 得到 `1 ^ 2 = 3`，向下到 `(1,0)` 得到 `1 ^ 3 = 2`；
- 从 `(0,1)` 到终点得 `3 ^ 4 = 7`，从 `(1,0)` 到终点得 `2 ^ 4 = 6`；
- 终点可达的集合是 `{6, 7}`，从小到大枚举，第一个是 `6`，输出 `6`。

代码中把可达标记写成赋值 `1`，判断时用 `== 1` 和 `== inf` 区分，效果等价于布尔标记。

## 复杂度

时间复杂度：`O(m * n * 1024)`，每个格子对 1024 个异或值各做常数次转移，题目保证 `m * n <= 1000`，总量约一百万。
空间复杂度：`O(m * n * 1024)`，即三维状态数组的大小。

## Code

```python3
class Solution:

    def minCost(self, grid: list[list[int]]) -> int:
        n, m = len(grid), len(grid[0])
        f = [[[inf] * 1024 for _1 in range(m)] for _2 in range(n)]
        f[0][0][grid[0][0]] = 1

        for i in range(n):
            for j in range(m):
                for s in range(1024):
                    if f[i][j][s] == inf:
                        continue
                    if i + 1 < n:
                        state = s ^ grid[i + 1][j]
                        f[i + 1][j][state] = 1
                    if j + 1 < m:
                        state = s ^ grid[i][j + 1]
                        f[i][j + 1][state] = 1

        for state in range(1024):
            if f[n - 1][m - 1][state] == 1:
                return state
```
## Code（其他语言版本，编辑器中为可切换 tab）

### C++

```cpp
class Solution {
public:
    int minCost(vector<vector<int>>& grid) {
        int n = grid.size(), m = grid[0].size();
        vector<vector<vector<int>>> f(n, vector<vector<int>>(m, vector<int>(1024, INT_MAX)));
        f[0][0][grid[0][0]] = 1;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                for (int s = 0; s < 1024; s++) {
                    if (f[i][j][s] == INT_MAX) {
                        continue;
                    }
                    if (i + 1 < n) {
                        int state = s ^ grid[i + 1][j];
                        f[i + 1][j][state] = 1;
                    }
                    if (j + 1 < m) {
                        int state = s ^ grid[i][j + 1];
                        f[i][j + 1][state] = 1;
                    }
                }
            }
        }

        for (int state = 0; state < 1024; state++) {
            if (f[n - 1][m - 1][state] == 1) {
                return state;
            }
        }
        return 0;
    }
};
```
