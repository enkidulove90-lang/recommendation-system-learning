# ConfSMoE：置信度引导的稀疏混合专家门控

**英文标题**: Rethinking Gating Mechanism in Sparse MoE: Handling Arbitrary Modality Inputs with Confidence-Guided Gate
**arXiv ID**: 2505.19525
**会议**: ICML 2026 (Poster)
**生成时间**: 2026-07-31

---

## 主要贡献

重新思考稀疏MoE门控机制的根本缺陷：揭示softmax门控导致专家崩塌的梯度动力学原因（梯度集中+负载均衡损失反向梯度），提出Confidence-Guided门控网络（ConfNet），用Sigmoid替代Softmax以任务置信度为路由信号。无需额外负载均衡损失即可自然缓解专家崩塌，同时具备天然抗模态缺失能力。提出两阶段模态填补策略：预填补（随机采样K个实例平均）→ 跨模态精炼。

## 创新点

1. 创新点1：ConfNet门控机制——每个expert配备独立的置信度估计子网络，将token embedding映射为标量logit后经Sigmoid输出gate score ∈ (0,1)。路由信号从token/embedding相似度转变为任务相关置信度，打破softmax下“富者愈富”的专家收敛循环。
2. 创新点2：理论证明负载均衡损失的梯度冲突——通过Jacobian分析证明softmax门控下负载均衡损失产生的梯度与主任务梯度方向相反，导致专家选择出现“正弦波”式不稳定振荡。ConfNet通过解耦门控与负载均衡，自然消除此冲突。
3. 创新点3：两阶段模态缺失处理——Pre-Imputation（从训练集同模态池中随机采样K个实例平均，捕获模态共性特征）→ Cross-modal Refinement（实例级跨模态对齐精炼初始估计），使模型在任意模态组合下均可正常工作。
4. 创新点4：两种变体设计——ConfSMoE-T在token级别做置信度融合（每个token独立评分），ConfSMoE-E在expert级别聚合（token级表示先按expert分组平均再评分）。

## 方法论

ConfNet门控网络：输入embedding → 置信度估计网络（小型MLP）→ Sigmoid → gate score g_i ∈ (0,1)。训练目标：L = L_task（交叉熵）+ L_conf（gate score与GT标签概率的MSE）。对比传统softmax门控的L = L_task + λ·L_load_balance，ConfNet仅需一个轻量级MSE项。

## Benchmark 与数据集

- MIMIC-III（重症监护临床数据，多模态医疗）
- MIMIC-IV（升级版临床数据库）
- CMU-MOSI（多模态情感分析，视频+音频+文本）
- CMU-MOSEI（扩展版多模态情感数据集）
实验设置覆盖完整模态、随机缺失模态、固定缺失模态三种场景。

## 实验效果

ConfNet门控在F1和AUC双指标上全面超越所有基线：Softmax门控、Softmax+Load Balance Loss、Gaussian门控、Laplacian门控。消融实验表明：(1)移除imputation模块导致F1最多下降6.21%；(2)ConfNet和Laplacian门控在维持专家专业化的同时实现负载重分布，而严格的负载均衡（Softmax+LB Loss）反而抑制专家专业化；(3)在模态缺失场景下ConfNet的鲁棒性显著优于所有softmax基方法。

## 对推荐系统 Agent 开发的借鉴

对推荐系统Agent开发的借鉴价值：(1)算法设计：ConfNet的置信度门控可直接迁移到多模态推荐Agent中，用任务置信度（如CTR预估概率）替代softmax模态路由，使门控与推荐目标对齐；(2)系统架构：Sigmoid门控+轻量级MSE损失的组合比softmax+负载均衡损失更稳定易训，适合Agent在线学习场景；(3)模态缺失处理：两阶段填补策略可用于推荐中常见的物品冷启动/模态缺失问题；(4)理论分析：Jacobian梯度分析方法可用于分析现有推荐MoE模型的门控稳定性。
