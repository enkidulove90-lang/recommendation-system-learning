📌 智能体如何看穿论文新意
写综述、做科研最头疼的一步：怎么判断一篇论文到底「新不新」、和已有工作差在哪、还有哪些空白没填？
这篇 *Novelty-Aware Agentic Retrieval* 给了一个可复现的答案：用六组件智能体流水线，把「比对论文贡献」拆成结构化多步推理——
🔧 它怎么做的 查询分析器把问题拆成 2-4 个重写查询 → 检索器用 FAISS + ReAct 循环补召回 → 排序器筛 Top-5 → 贡献提取器用模式引导解码抽出「问题 / 方法 / 贡献 / 声称新颖性」四字段 → 比较代理三遍比对（重叠 / 差异 / 空白）→ 答案生成器出最终报告。
📊 最反直觉的一个数 Table 5：全排序器 P@5 = 1.000，吊打 BM25(0.733)、Dense(0.667)、Hybrid(0.667)；全系统 nDCG@5 = 0.752，也优于基线 RAG(0.548)。相当于在 100 个相关结果里精准锁定，而代价只是多加了一层排序。
⚠️ 它没解决一切 论文自承：语料仅 100 篇、相关性标签作者自标、单评分者评估。判断：依赖 GPT-4o 等专有 LLM，复现受限；空白矩阵只验了 20 个采样单元，统计效力有限。
真正该问的是：在冷启动 / 数据分布漂移场景下，它会不会失效？
