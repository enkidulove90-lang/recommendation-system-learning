OSWorld：给 AI Agent 的「真实电脑考场」，369 题最强模型仅做对 12%
💻 AI 替你操作电脑，到底行不行？先让它考过 OSWorld 🧠 一句话定性 OSWorld（NeurIPS 2024）是第一个「真·电脑环境」基准：不是模拟、不是单 App 沙盒，而是直接在你熟悉的 Ubuntu / Windows / macOS 里，给 Agent 369 道真实操作题。 📊 它到底考什么 · 跨系统：Ubuntu、Windows、macOS 真实虚拟机 · 跨应用：Chrome、VS Code、GIMP、LibreOffice、Thunderbird……真实桌面 + Web App · 真评测：execution-based 执行式打分——不是「选哪个选项」，而是真去点、真去改，再跑脚本验证结果对不对 · 369 道任务全部来自真实电脑使用场景，每题带初始状态配置 + 自定义评估脚本，可复现 📉 扎心数据 人类能完成 72.36% 的任务；评测时最强模型（GPT-4V 系）只做对 12.24%。 差距主要卡在两件事：GUI 定位（按钮在哪、点哪个）+ 操作常识（哪个菜单里能找到功能）。说白了，Agent 看得懂图，但「不会用电脑」。 🌟 为什么这篇老 benchmark 现在还值得读 之前的电脑 Agent 基准要么是假环境、要么只盯单个软件，根本反映不了真实办公的复杂度。OSWorld 第一次把「多 App、跨系统、开放式任务」放进同一个可复现考场，直接把「电脑助手」的研究往前推了一大步。 （补充：项目后来出了 OSWorld-Verified 升级版，新榜首已逼近 86%，进步飞快——但 12% 这个原始数字足够说明起点有多难。） 💡 完整论文已整理，关注我持续拆解 Agent / 多模态方向硬核论文 📚 📄 论文：https://arxiv.org/abs/2404.07972 💻 代码 GitHub：https://github.com/xlang-ai/OSWorld 🌐 项目主页：https://os-world.github.io
