# 论文标准化解析 Skill

## 强制输出格式

每篇论文的 Summary 必须包含以下 **8 个必填区块**，缺一不可：

### 1. 头部元信息
```markdown
# 中文标题
**英文标题**: 
**arXiv ID**: 
**会议**: (无则写"待查")
**作者**: (机构标注)
**GitHub**: (无则写"待查")
**创新评级**: ⭐(1-5)
```

### 2. 主要贡献 (≥2句)
```
## 主要贡献
提出XXX框架，解决XXX问题。核心思路是XXX。
```

### 3. 创新点 (≥3条，编号)
```
## 创新点
1. 
2. 
3. 
```

### 4. 方法论 (≥2句)
```
## 方法论
采用XXX架构。关键模块包括XXX。训练目标为XXX。
```

### 5. Benchmark 与数据集 (表格形式)
```
## Benchmark 与数据集
| 数据集 | 规模 | 模态 | 来源 |
|--------|------|------|------|
| Amazon-Baby | XX万交互 | 图像+文本 | Amazon Reviews |
```

### 6. 基线方法(Backbone/Baseline) (必须列出)
```
## 基线方法
- 协同过滤基线: LightGCN, NGCF, ...
- 多模态基线: MMSSL, LATTICE, ...
- 骨干网络: SASRec / LightGCN / ... (embed dim=64, layers=2)
```

### 7. 实验效果 (必须列出具体数字)
```
## 实验效果
| 数据集 | 指标 | 最强基线 | 本方法 | 提升 |
|--------|------|---------|--------|------|
| Amazon-Baby | NDCG@20 | 0.xxxx | 0.xxxx | +x.x% |
```

### 8. 对推荐系统的借鉴 (≥2条)
```
## 对推荐系统的借鉴
1. 
2. 
```

## 数据来源优先级

1. **论文PDF全文** — 最优先，直接提取数字
2. **arXiv HTML (ar5iv)** — 备选
3. **Semantic Scholar / 博客** — 补充
4. **WebSearch** — 最后手段

## 质量检查

- [ ] GitHub链接是否已填入？
- [ ] 数据集表格是否有具体规模数字？
- [ ] 基线方法是否列出≥3个？
- [ ] 实验效果是否有具体提升百分比？
- [ ] 创新评级是否合理(1-5星)？
